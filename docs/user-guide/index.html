What you need before you start

None of these is strictly required — EOS Connect starts with defaults and a demo solar curve so you can look around. They are what it takes to have it do something useful.

  • Somewhere to run it: Home Assistant, a Docker host, or Python 3.13.
  • A way to read your house: Home Assistant or openHAB, with a sensor reporting household consumption in watts.
  • Your battery's capacity and its state-of-charge sensor.
  • For control rather than advice: a supported inverter, or EVCC in front of one.
  • An electricity tariff — a dynamic one is where this earns its keep, but a fixed rate works.
